Actual frozen development scenes captured in the Codex in-app browser at its default 1280×720 viewport. These scenes use production inventory, character art, and atlas components with staged level-10 equipment. They do not advance simulation, access saved discovery, or drive gameplay. All five pages reported no console errors.
