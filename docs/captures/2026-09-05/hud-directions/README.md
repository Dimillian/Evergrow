# HUD direction captures

Native Canvas PNG exports from the local in-app browser. All scenes are frozen and do not run gameplay or touch saves.

- `evergrowing-reliquary-ready.png`, `evergrowing-thornbound-ready.png`, `evergrowing-astral-ready.png`: original three proposal exports from `/hud-directions.html`, detail view.
- `evergrowing-astral-live.png`: selected, implemented HUD from `/hud.html?state=healthy`, using actual player resource/ability presentation and the native enemy plate.
- `evergrowing-astral-live-states.png`: actual healthy, damaged, and depleted states from `/hud.html`.
- `evergrowing-astral-narrow-states.png`: the same states at 390px from `/hud.html?size=narrow`.

The user selected The Astral Instrument. The game uses its procedural frame, with no raster HUD assets or theme switching.
