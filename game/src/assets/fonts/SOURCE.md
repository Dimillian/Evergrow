# Barlow Medium — interface numerals

Copyright 2017 The Barlow Project Authors (https://github.com/jpt/barlow).

Bundled unmodified static Medium font under SIL Open Font License 1.1. Registered as `Evergrow Numerals` with a numeric-only Unicode range, so display lettering remains Pixelify Sans. The same Medium outlines serve all UI weights for consistent legibility.

- [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/barlow)
- [Original font binary](https://raw.githubusercontent.com/google/fonts/main/ofl/barlow/Barlow-Medium.ttf)
- [Original license](https://raw.githubusercontent.com/google/fonts/main/ofl/barlow/OFL.txt)

Retrieved 2026-09-06. Exact license retained as `Barlow-OFL.txt` beside the font and in `game/public/licenses/Barlow-OFL.txt`. Runtime loading uses the bundled asset only.
